# CAB System - Test Cases

## 1. Thông tin chung

| Thuộc tính | Nội dung |
|---|---|
| Tên dự án | CAB System - Nền tảng đặt xe |
| Phiên bản | 1.0 |
| Phạm vi | MBB |
| Nguồn kiểm thử | SRS.MD |
| Trạng thái mặc định | Not Executed |

## 2. Danh sách file

- `customer.md` — Test Case cho Khách hàng
- `driver.md` — Test Case cho Tài xế
- `operator.md` — Test Case cho Nhân viên vận hành
- `admin.md` — Test Case cho Quản trị viên
- `payment_provider.md` — Test Case cho Nhà cung cấp thanh toán
- `notification_provider.md` — Test Case cho Nhà cung cấp thông báo
- `system_integration.md` — Test Case tích hợp, bảo mật, mất kết nối và phạm vi MBB
- `traceability.md` — Ma trận truy xuất Test Case ↔ AC/UC/FR/EX

## 3. Quy ước

- **Pass:** Kết quả thực tế phù hợp với Expected Result.
- **Fail:** Kết quả thực tế không phù hợp với Expected Result.
- **Not Executed:** Chưa thực hiện kiểm thử.
- Nội dung được xây dựng theo SRS hiện tại, không tự bổ sung các nghiệp vụ ngoài phạm vi MBB.
